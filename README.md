# Serverless AI Inference Execution Kernel

Application-level OS kernel untuk eksekusi fungsi AI/inference secara cepat.

## Features

- FastAPI REST API
- Function registry
- Dynamic function execution
- Echo function
- Uppercase function
- Execution time measurement
- Error handling
- Automated testing
- Swagger API documentation

## Run

```bash
source .venv/bin/activate
uvicorn app.main:app --reload
